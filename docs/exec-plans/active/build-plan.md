## 단계 12: 클로즈 베타

**누가 쓰나**: DS 데이터센터·AI센터의 소수 팀(처음 몇 명). **무엇을 하나**: 자기들의 LLM + 하네스 + 툴 조합을 시나리오에 돌려 보고 순위를 본다.
날짜는 적지 않는다. 작업량을 재 보기 전에 날짜를 적으면 거짓말이 된다. 대신 **순서, 크기, 끝났다고 말할 수 있는 조건**을 적는다.

|---|---|---|---|
| 1 | 시나리오 만들기 UX 점검 (#75): 템플릿에서 시작해 블록으로 고치고, 시험 실행과 시험지 점검(기준선)까지 | 중간 | 처음 쓰는 사람 흐름을 브라우저로 끝까지 따라가 막힘이 없고, 편집기에서 기준선 점수와 경고를 본다 |

| 3 | 방 온도 분포·공기 흐름 지도 (#69): 목업을 먼저 보여 드리고 승인받는다. CFD가 아니라는 표시를 단다 | 중간 | 승인된 목업대로 서버룸 화면에서 보이고 캡처로 확인한다. **상태: 끝남** — [설명](../../design-docs/airflow-map.md) |

## 알려진 간극

- **HPC센터에 지하층이 없다.** 실제는 지하 2층에 기계실·전기실이 있다. 층 번호 0과 음수가 3D 단면에서 비싸서(층 순서가 지상 1층을 0번으로 가정한다) 만들지 않았고, 대신 전기실·기계실·창고를 서버 층마다 둔다. 연면적도 층마다 같은 바닥이라 실제(53,508 ㎡)보다 크다(75,240 ㎡).
- **수전 용량의 합은 설계 부하**(가동률 0.6)이지 명판 최대치가 아니다. 명판으로 더하면 같은 랙 수에서 HPC센터가 117 MW라 108 MW를 지킬 수 없다. 팹과 연구동 안의 서버룸은 세지 않는다. 화성 외 사업장의 용량은 추정이다.
- **방 패널의 설비 길에 옥상이 없다.** 건물 밖 설비는 마당에만 놓는다. 옥상 플랜트(부모가 건물인 칠러·발전기)는 3D가 아직 그리지 않는다.

- **정답만으로 만점인 내장 시나리오가 7개**다 ([측정의 신뢰](../../design-docs/measurement.md)). 단계 12의 두 번째 일이 이것을 줄인다.
- **시나리오 블록 중 `set_outdoor_temp`, `network_degrade`는 계획 상태**이고, 제어 가능 요소표에 없는 제어(UPS 모드, ATS 수동 전환, CDU 펌프 속도, vMotion, 디스크 교체)가 있다 ([제어표](../../design-docs/controllability.md)).
- **GoClaw 에이전트 목록과 Langfuse 읽기는 문서만 보고 만들었다.** GoClaw `GET /v1/agents`는 공식 문서에 응답 모양과 페이지 처리가 없어 `{"agents": [...]}`를 기본으로 읽고 커서·`total`+`offset`도 따라간다. Langfuse는 v2 관찰 API를 먼저 쓰고 404이면 옛 경로로 간다. 둘 다 실제 서버에서 "말 걸어 보기"로 확인해야 한다 ([ADR-0085](../../design-docs/adr/0085-telemetry-adapters.md)).
- **진짜 하네스 세 종은 대본 모델로만 끝까지 돌았다.** 배관(연결, 툴 호출, 채점, 순위표)은 확인했고 모델의 판단력은 못 쟀다. 모델이 닿는 기계에서 [런북](../../design-docs/harness-e2e.md)대로 다시 돌려야 한다.
- **느린 기계에서 세계는 줄어들 뿐 멈추지 않는다.** 프레임이 늦으면 사람·방문객·공기 입자가 단계마다 절반이 되고(최소 하나), 갱신이 덜 잦아진다. 그래픽 카드 있는 PC에서 25 ms 기준이 실제로 맞는지는 이 환경(소프트웨어 렌더링)에서 못 쟀고, 베타 사용자 PC의 체감으로 확인해야 한다. 설정 화면은 그래픽 한 줄뿐이며 화면 색(피드백 1)이 이어서 더한다 ([웹 화면](../../design-docs/web-ui.md#그래픽-품질과-줄이기)).
- **공기 흐름 지도는 CFD가 아니다.** 냉방기 풍량과 랙 발열로 방향과 세기를 계산한 그림이고 화면에도 그렇게 적혀 있다 ([설명](../../design-docs/airflow-map.md)). 서버룸의 사람은 장식이며 고장을 고치지 않는다.
- **첫 화면은 예산(700 kB)에 빠듯하다.** three.js가 대부분이고 공기 흐름 지도, 연결·벤치마크·실험·실행 화면은 처음 열 때 따로 받는다. 화면을 더하면 먼저 지연 로딩을 생각한다.
- **접근성 트리는 사람이 훑은 표가 없다.** 이번에 화면별로 이름·제목 단계·같은 이름 버튼·캔버스 안내를 훑어 고쳤고, 방 안 층의 3D와 연결 창 같은 깊은 상태는 axe에만 맡긴다.
- **로그인은 자리만 있다** (ADR-0044). 지금은 공유 비밀번호 수준이다.
