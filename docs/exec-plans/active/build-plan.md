## 단계 12: 클로즈 베타

**누가 쓰나**: DS 데이터센터·AI센터의 소수 팀(처음 몇 명). **무엇을 하나**: 자기들의 LLM + 하네스 + 툴 조합을 시나리오에 돌려 보고 순위를 본다.
날짜는 적지 않는다. 작업량을 재 보기 전에 날짜를 적으면 거짓말이 된다. 대신 **순서, 크기, 끝났다고 말할 수 있는 조건**을 적는다.

| 순서 | 일 | 크기 | 끝났다고 말하는 조건 |
|---|---|---|---|
| 1 | 시나리오 만들기 UX 점검 (#75): 템플릿에서 시작해 블록으로 고치고, 시험 실행과 시험지 점검(기준선)까지 | 중간 | 처음 쓰는 사람 흐름을 브라우저로 끝까지 따라가 막힘이 없고, 편집기에서 기준선 점수와 경고를 본다 |
| 2 | 운영을 재는 시나리오: 정답만 말하면 만점인 내장 시나리오 7개에 조치·최종 상태 채점을 더하고, 아직 없는 블록(바깥 기온, 네트워크 열화)을 만든다 | 큼 | 정답만 아는 기준선이 만점을 못 받는 시나리오가 늘고, 목록이 시험으로 고정된다 |
| 3 | 방 온도 분포·공기 흐름 지도 (#69): 목업을 먼저 보여 드리고 승인받는다. CFD가 아니라는 표시를 단다 | 중간 | 승인된 목업대로 서버룸 화면에서 보이고 캡처로 확인한다 |
| 4 | 진짜 하네스로 끝까지 (#60): OpenCode, LangGraph, OpenClaw를 설치해 커넥터로 실험 하나를 완주 | 큼 | 세 하네스가 각자 실험을 끝내고 결과가 순위표에 뜬다. 막힌 곳은 고쳐서 문서에 남긴다 |
| 5 | UX 재측정(UX004)과 접근성 트리 점검 (#64 일부) | 작음 | `pnpm ux` 통과, 점수를 비교표로 남긴다 |
| 6 | 전체 하네스 + 베타 사용 안내(README 시작하기 갱신) | 작음 | `run-all --with-coverage` 통과 |

## 단계 13: 오픈 (프로덕션 레디)

**누가 쓰나**: 여러 팀. 베타 피드백을 반영한 뒤에 시작한다.

| 일 | 크기 | 끝났다고 말하는 조건 |
|---|---|---|
| 베타 피드백 반영 | 중간 | 베타에서 나온 막힘이 모두 고쳐졌거나 이유와 함께 미뤄졌다고 적혀 있다 |
| 사람 식별(OIDC 로그인)과 소유자 권한 (ADR-0044의 자리를 실제로) | 큼 | 로그인한 사람이 자기 에이전트·실험의 주인으로 보이고 남의 것은 못 고친다 |
| 운영성: 백업과 복구, 버전 업그레이드에서 데이터 보존, 장시간 실행 | 큼 | 백업에서 복구한 서버가 같은 결과를 내고, 업그레이드 시험이 통과한다 |
| 부하와 용량: 동시 실행, 큰 세계, 오래 켜 둔 서버 실측 | 중간 | 용량 문서가 실측 숫자로 갱신된다 |
| 보안 점검: 비밀 취급, 입력 검증, 감사 기록 | 중간 | 점검 목록과 결과가 문서에 있다 |
| 배관 랙·유리 연결 통로 같은 남은 세계 표현 (#64 일부) | 중간 | 빌더에서 만들고 3D에서 보인다 |
| 아직 없는 제어: UPS 모드, ATS 수동 전환, CDU 펌프 속도, vMotion, 디스크 교체 | 큼 | 제어 가능 요소표에 줄이 늘고 시험이 증명한다 |
| 최종 UX 점수와 전달 보고(쉬운 말, 한계 포함) (#59) | 작음 | 보고서가 있다 |

## 알려진 간극

- **정답만으로 만점인 내장 시나리오가 7개**다 ([측정의 신뢰](../../design-docs/measurement.md)). 단계 12의 두 번째 일이 이것을 줄인다.
- **시나리오 블록 중 `set_outdoor_temp`, `network_degrade`는 계획 상태**이고, 제어 가능 요소표에 없는 제어(UPS 모드, ATS 수동 전환, CDU 펌프 속도, vMotion, 디스크 교체)가 있다 ([제어표](../../design-docs/controllability.md)).
- **진짜 하네스 세 종으로 끝까지 돈 실험은 아직 없다.** 커넥터 시험은 가짜 하네스로 했다. 단계 12의 네 번째 일이다.
- **방의 온도와 공기 흐름은 지도로 볼 수 없다.** 물리는 있으나 화면이 없다.
- **로그인은 자리만 있다** (ADR-0044). 지금은 공유 비밀번호 수준이다.
