# 클로즈 베타 차수 계획

2026-11-05 연수 님과 나눈 설계(ADR-0083~0096)는 전부 클로즈 베타에 들어간다. 오픈은 프로덕션 레디(로그인·권한, 백업·복구·업그레이드, 부하·용량, 보안)만 남는다. **차수마다 구현 → tsc·lint·구조 검사 → 바뀐 테스트만 → push**하고 피드백을 받는다(연수 님 결정, 2026-11-06). 전체 검사(`run-all`)·UX 측정·래칫은 4차까지 push한 뒤 **한 번만** 돌리고, 깨진 것을 고쳐 마지막 push를 한다. 구현은 Sonnet이 둘씩 나란히(별도 worktree).

| 차수 | 묶음 | 근거 | 상태 |
|---|---|---|---|
| 1 | 건물 실측·잠금(#87), 성능·멈춤 대신 줄이기(#88), 연결·텔레메트리 어댑터(#89), 새 세계·빌더 재설계·색·폭·실험 설명(#90), 토폴로지 ①(층 셋·고장·알람·영향 범위·접기: **구현 끝**, [설명](../../design-docs/topology.md)), 랙 실장·컨테인먼트 안·펌웨어 템플릿(#91) | ADR-0081~0085, 0083, 0084, 0101 | 끝 (push 1a~1d) |
| 2 | **2a**: 서비스 층, OS 층 1차(가짜 셸·고장 10), OS 고장 템플릿 5(**구현 끝**, [설명](../../design-docs/service-os-layer.md)). **2b**: 토폴로지 ②(에이전트 맥박·리플레이·나란히·결과 첫 줄: **구현 끝**, [설명](../../design-docs/topology.md)). **2c**: 복구 우선 채점(**구현 끝**, [설명](../../design-docs/measurement.md#3-서비스가-있는-시나리오는-복구-우선으로-채점한다-req-088-adr-0091-adr-0104)) | ADR-0091, 0102, 0084, 0103 | 2a~2c 끝 (push 대기) |
| 3 | 툴 범위·현실 수준 꼬리표·툴 설명 표준·툴 고르기 점검(**기본 툴 묶음을 현실 수준 흔함·드묾·없음별 묶음으로 다시 정리한다. 2c에서는 OS 고장이 풀리도록 `run_command` 하나만 기본 묶음에 먼저 넣었다**), 에스컬레이션 `ask_human`·고장 범위, 절차서 변수·SOP 준수 채점, 운영 모드(고장 발생기·실시간/빨리 감기·당겨 보는 모니터링·운영 지시문·설계 가이드·기준 에이전트·타임라인), 도메인 범위·가상 담당자(벤더 리드타임)·작업 티켓 | ADR-0087, 0094, 0098 | 대기 |
| 4 | 서비스부터 세계 만들기 + 저장해 두기 패턴(템플릿), 홈 = 경영진 한 장 + 엔지니어 근거, 벤치마크 pass^k·실패 유형·버전 세트·비용, 데이터 화면과 표준 내보내기·불변 사건·버전 묶음 | ADR-0092, 0089, 0088 | 대기 |
| 마감 | 전체 검사·UX 재측정·래칫 한 번, 깨진 것 고치기, 클로즈 베타 마감 보고(한국어·파인만·한계·UX 점수) | — | 대기 |

## 차수마다 지키는 것
- 목업 먼저(화면이 있는 묶음은 승인 뒤 구현): 에스컬레이션 카드, 툴 고르기, 서비스부터 세 화면, 경영진 한 장, 데이터 화면, 운영 모드 타임라인.
- 글의 잣대(`world-builder-review.md` "두 번째 검토"): 해요체, 한 문장 한 정보, 아라비아 숫자+단위, "~할 수 있어요" 겹치기 금지, 시스템·개발자 말 금지("벽시계" → "실제 시간"), 버튼은 결과.
- 실험에 들어가는 정보가 앞, 돈은 사고 비용·전기요금에서만 의미.
- 정직한 한계를 문서에.

## 오픈 단계에 함께 가는 것
- OIDC(사내 SSO) 로그인·권한 위에 **사용자 등급**(Kaggle식, 연수 님 제안 2026-11-06): 활동량이 아니라 기여로만 — 새싹(첫 실험) → 기여자(내 시나리오·템플릿·절차서를 남이 씀) → 전문가(벤치 상위권 또는 변별력 통과 시나리오 n개) → 마스터(대회 입상 또는 기준 에이전트를 이긴 설계 공개) → 그랜드마스터(여러 대회 입상 + 남이 재현). 프로필 배지·기여 목록·리더보드 표시. 사람의 답(에스컬레이션·평가 라벨)도 기여로 센다. 등급 계산은 사용자 ID 기준으로 설계해 SSO가 붙으면 그대로 잇는다.

## 오픈 뒤 로드맵(베타 밖)
파워 캐핑(ADR-0096: Redfish 전력 제한·전기요금·시나리오 3), 모델 플러그인·모델 대 모델(ADR-0095), 대회 모드(참가 등록·비공개 세트·리더보드 공개 시점), 쌍둥이 ②~④, 컨테이너 층(kubectl), 진짜 VM 섞기, 가져오기(ADR-0084 조건). (연수 님 결정 2026-11-06: 5차였던 파워 캐핑·모델 플러그인은 오픈 뒤로.)
