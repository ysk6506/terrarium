# 클로즈 베타 차수 계획

2026-11-05 연수 님과 나눈 설계(ADR-0083~0096)는 전부 클로즈 베타에 들어간다. 오픈은 프로덕션 레디(로그인·권한, 백업·복구·업그레이드, 부하·용량, 보안)만 남는다. **차수마다 구현 → tsc·lint·구조 검사 → 바뀐 테스트만 → push**하고 피드백을 받는다(연수 님 결정, 2026-11-06). 전체 검사(`run-all`)·UX 측정·래칫은 3차까지 push한 뒤 **한 번만** 돌리고, 깨진 것을 고쳐 마지막 push를 한다. 구현은 Sonnet이 둘씩 나란히(별도 worktree).

**2026-11-06 연수 님 결정: 클로즈 베타는 셋으로 나눈다.** 1차는 이미 push된 것(옛 1·2차), 2차는 지금 돌고 있는 묶음과 오늘 승인한 세계 만들기 재설계(ADR-0107), 3차는 나머지와 마감이다.

## 차수마다 지키는 것
- 목업 먼저(화면이 있는 묶음은 승인 뒤 구현): 서비스부터 세 화면·직접 짓기(승인됨, ADR-0107), 경영진 한 장, 데이터 화면, 운영 모드 타임라인.
- 글의 잣대(`world-builder-review.md` "두 번째 검토"): 해요체, 한 문장 한 정보, 아라비아 숫자+단위, "~할 수 있어요" 겹치기 금지, 시스템·개발자 말 금지("벽시계" → "실제 시간"), 버튼은 결과.
- 실험에 들어가는 정보가 앞, 돈은 사고 비용·전기요금에서만 의미.
- 정직한 한계를 문서에.

## 오픈 단계에 함께 가는 것
- OIDC(사내 SSO) 로그인·권한 위에 **사용자 등급**: 연수 님 결정(2026-11-06, ADR-0122)으로 Kaggle식 **계급은 대회 메달 수로만** 정한다(새싹 → 참가자 → 전문가 → 마스터 → 그랜드마스터, 낸 사람의 것). 메달·계급 함수와 대회 포트는 끝났고, **프로필·리더보드에 계급을 보이는 일은 대회 모드와 함께** 한다. 활동·기여는 계급이 아니라 **칭호**가 말한다(끝). 사람의 답(에스컬레이션·평가 라벨)을 기여로 세는 일은 남아 있다. 칭호와 계급은 사용자 ID 기준으로 설계해 SSO가 붙으면 그대로 잇는다.

**2026-11-06 연수 님 결정: 3차는 뒤로 미루고, 오픈 뒤 로드맵에 있던 ADR-0107 결정 6(점선 칩 전부)과 깊은 OS 흉내(ADR-0117)를 지금 한다.** 순서: 컨테이너 층(o1) · SDN 네트워크(o2) → 애플리케이션 층 → 사이트·DR → 스토리지 지역 복제·분산 SQL·멀티 AZ → 깊은 OS 흉내(**끝**, REQ-098).

## 오픈 뒤 로드맵(베타 밖)
깊은 OS 흉내(**끝**, REQ-098, [설명](../../design-docs/service-os-layer.md)), SDN·클라우드 네이티브 네트워크(**끝**, REQ-097, [설명](../../design-docs/sdn-network-layer.md)), LLM API 등록(**끝**, REQ-099), 세계 인기·좋아요·칭호(**끝**, REQ-101, [설명](../../design-docs/ranking-and-titles.md)) — 계급 모델(메달·계급 함수와 대회 포트)은 준비됐고 화면은 대회 모드와 함께, 서버리스 컴퓨트(컨테이너 오케스트레이션·DRS·멀티클러스터는 끝 — REQ-096), 지역 복제 스토리지, DR 사이트·멀티 사이트, 서비스 메시(ADR-0107 결정 6), 파워 캐핑(ADR-0096: Redfish 전력 제한·전기요금·시나리오 3), 모델 플러그인·모델 대 모델(ADR-0095), 대회 모드(참가 등록·비공개 세트·리더보드 공개 시점), 쌍둥이 ②~④, 진짜 VM 섞기, 가져오기(ADR-0084 조건). (연수 님 결정 2026-11-06: 5차였던 파워 캐핑·모델 플러그인은 오픈 뒤로.)
