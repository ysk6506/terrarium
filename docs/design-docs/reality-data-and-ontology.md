# 현실 데이터와 모델 (옮김, [ADR-0192](adr/0192-terrarium-returns-to-its-first-goal.md))

테라리움은 이것을 만들지 않아요. 현실 시스템에서 데이터를 받아 모델에 대응시키는 일은 다른 프로젝트가 맡아요. 테라리움은 처음의 제품 목표까지만 하고, 그 프로젝트와는 세계 스냅샷(들어옴)과 판정 기록(나감) 두 파일로만 이어져요.

옮기기 전의 설계는 [보관함](../archive/moved-out/reality-data-and-ontology.md)에 그대로 있어요. 더 고치지 않아요. 이 자리는 앞선 결정 기록의 링크가 끊기지 않게 남겨 둔 표지예요.
