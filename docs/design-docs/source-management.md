# 소스 관리 (옮김, [ADR-0192](adr/0192-terrarium-returns-to-its-first-goal.md))

테라리움은 이것을 만들지 않아요. 소스의 동기화 주기, 실행 기록, 안전장치은 다른 프로젝트가 맡아요. 테라리움은 처음의 제품 목표까지만 하고, 그 프로젝트와는 세계 스냅샷(들어옴)과 판정 기록(나감) 두 파일로만 이어져요.

옮기기 전의 설계는 [보관함](../archive/moved-out/source-management.md)에 그대로 있어요. 더 고치지 않아요. 이 자리는 앞선 결정 기록의 링크가 끊기지 않게 남겨 둔 표지예요.
