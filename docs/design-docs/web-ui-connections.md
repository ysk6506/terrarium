# 연결 화면 (REQ-051~053, ADR-0048)

[웹 화면](web-ui.md)에서 나눠 둔 절이다. 동작 규칙은 [ADR-0048](adr/0048-connections-screens.md)에 있다.


- **순서는 내 연결, 하네스 종류, 기준 에이전트다**(베타 피드백 15~17, [목업](mockups/editor-connections-mockup.html)). 맨 위 "내 연결"은 카드 한 장에 이름·연결됨·종류·주소 종류·마지막 사용이 한 줄이고, **"말 걸어 보기"가 카드 맨 위 오른쪽 첫 버튼**이다(누르면 카드 안에서 열린다). 그 아래 "에이전트 37개 · 이름으로 찾기 · 목록 펼치기" 한 줄과, 숨긴 이유 한 줄 + "모두 보기"가 있고 하네스의 부연 설명은 "더 알아보기"에 접힌다. 다시 확인·계속 쓰기·고치기·지우기와 태그는 "설정"에 접힌다(`ui/pages/connection-card.tsx`). 그 아래 "연결 더하기 — 어떤 하네스인가요?" 카드(하네스 프로토콜·OpenCode·LangGraph·GoClaw·Hermes·HTTP API, 나머지 방식은 뒤에)를 누르면 그 종류가 골라진 폼이 열리고 필요한 칸만 물어본다. 맨 아래 **내장 기준 에이전트는 접혀** 있고(변별력 점검에 쓰인다는 한 줄) 펼쳐도 "말 걸어 보기"가 없다. 어느 연결이 기준 에이전트인지는 커넥터 종류(`scripted`)로 가른다(`logic/connection-places.ts`).
- **카드는 툴 주소가 어느 쪽인지 말한다.** "실행 주소(등록 없음)"는 테라리움이 실행마다 만들어 넘기는 주소, "슬롯 주소(한 번 등록)"는 연결마다 고정된 주소다([하네스 프로토콜의 MCP 주소 절](harness-protocol.md)). 툴이 함수 호출이면 "함수 호출(주소 없음)". 연결 창의 "툴은 어떻게 받나요?" 안내는 접혀 있다.
- **폼은 커넥터가 그린다.** 연결 창은 `ConnectorSpec.fields`를 그대로 입력 칸으로 바꾼다(`ui/pages/connection-form.tsx`). 화면은 프로토콜을
  모르고, 커넥터가 늘면 화면도 따라온다. 맨 위에는 툴이 어떤 길로 가는지(`toolGuide`)를 보여 준다.
- **비밀 값은 되돌려 주지 않는다.** 저장된 비밀 칸은 "설정됨"이고, 비워 두면 그대로, 새로 적으면 교체, "저장된 값 지우기"를 누르면 `null`을 보낸다.
  서버 환경 변수 이름을 적는 칸은 드물게 쓰므로 접어 둔다.
- **HTTP API는 프리셋부터.** 커넥터가 `presets`를 주면 "OpenAI 호환 채팅 · 간단 JSON · 직접 적기" 가운데 하나를 고르고, 프리셋의 질문 몇 개만 먼저 보인다. 나머지 칸은 "고급 설정 N개"에 접히고, 프리셋이 하네스에 거는 약속(보내는 것, 받는 것)이 한 줄씩 있다. 순수 계산은 `logic/connection-presets.ts`.
- **트레이스는 연결마다 고른다.** 폼에 "이 하네스의 트레이스는 어디에 쌓이나요?"(없음 · ClickStack · Langfuse · 서버 기본값)가 있고, 고른 도구의 칸이 아래에 열린다(`logic/connection-traces.ts`).
- **숨긴 에이전트를 말한다.** 확인 결과와 연결 카드 위에 "에이전트 37개 중 1개가 보여요 · 36개는 상태가 'inactive'라 숨겼어요"와 "모두 보기" 버튼이 있다. 0개면 하네스가 준 원인을 그대로 쓴다(`logic/agent-census.ts`).
- **말 걸어 보기.** 연결 카드마다 에이전트를 고르고 한 문장(기본 "지금 할 수 있는 일을 한 줄로 말해 줘")을 보내면 답이 버튼 아래에 뜨고, 걸린 시간·툴 호출 수·"트레이스 이어짐 ✓" 또는 "안 이어짐 — 이유"가 한 줄로 나온다. 꺼진 버튼은 이유를 버튼에 쓴다(`ui/pages/connection-try.tsx`, `logic/try-talk.ts`).
- **저장 전에 "연결 확인"으로 연결되는지 본다.** 되면 발견한 에이전트와 걸린 시간, 안 되면 무엇을 바꿀지를 보여 준다.
- **지워질 연결은 모든 화면 위에서 알린다**(`meta.expiring`). 연결 목록의 각 줄에도 남은 날짜가 있고 "계속 쓰기"가 곁에 있다.
- **버전 기록은 한 화면에서 본다**: 새 버전부터, 바뀐 필드의 이전→이후, 날짜, 만든 사람, 그 버전으로 돌린 실험 수. "지금 실험을 만들면 새 버전이 생기는가"를
  맨 위에 미리 보여 주고, 같은 문구가 실험 만들기 2단계에도 나온다. 사람은 이름표·메모·속성으로 버전을 더하고 고친다.
- 실험을 만들 때는 메타데이터를 붙이고, 실험 목록은 `이름=값`으로 거를 수 있다. 실험 화면의 "시험한 대상"은 만든 시점의 하네스·에이전트·버전·메타데이터를 보여 준다.
- 순수 계산(폼의 시작값, 보낼 값, 빠진 것, 남은 기간 문장, 버전 변화 문장)은 `logic/connections.ts`, `logic/agent-versions.ts`에 있다.
