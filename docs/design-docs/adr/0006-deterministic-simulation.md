# ADR-0006 결정론적 시뮬레이션

## 맥락
벤치마크는 같은 조건으로 반복 실행되어야 에이전트를 비교할 수 있다 (REQ-001, REQ-014).

## 결정
- 시간과 난수는 `kernel`의 `Clock`, `Rng` 포트로만 쓰고, 월드는 이를 주입받는다. 시스템 시간·전역 난수·uuid를 읽을 수 있는 곳은 `kernel.entropy`와 `api`뿐이다.
- 월드의 상태 변화는 **이벤트 로그**에 기록되는 이벤트로만 일어난다. 상태는 (초기 월드 + 시드 + 이벤트 열)의 함수다.
- 스냅샷은 이 로그 위치와 상태를 담고, 리셋은 스냅샷으로 되돌린다.

## 이유
이벤트 로그가 있으면 재현, 스냅샷, 디지털 트윈에서 현실과의 차이 분석(REQ-015)이 같은 장치 하나로 해결된다.

## 버린 대안
- 가변 상태를 직접 수정: 재현과 감사가 어렵다.
- 시간 함수를 자유롭게 사용 + 테스트에서 패치: 패치를 빼먹은 곳에서 벤치마크 결과가 흔들린다.
