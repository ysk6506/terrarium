# ADR-0045 캠퍼스 꾸미기

## 맥락
ADR-0040으로 건물이 지도 속 자리에 섰지만, 사용자는 "사업장이 전부 초록 땅에 나무만 잔뜩 있다"고 했고 사업장 캠퍼스를 공개된 자료에서 찾아 현실처럼 꾸미라고 했다.
이미지 검색은 사진 설명 글만 돌려주었고 사진 자체는 볼 수 없었다. 그래서 설명 글(평택 약 289만㎡, 모듈형 외관, 가스·화학 동이 다리로 이어짐, 기숙사·카페·산책로·조각공원)과
앞서 쓴 지도를 근거로 삼았다.

## 결정
1. **빈 땅을 블록으로 나눈다.** 건물 둘레로 96m 칸에 12m 도로를 둔 격자를 깔고, 건물이 차지한 칸은 비운 채 나머지 칸마다 용도를 하나 정한다.
2. **용도는 열한 가지**: 사무동, 기숙사, 주차 건물, 유틸리티(기계동·냉각탑·굴뚝·배관 랙), 탱크 마당, 운동장, 연못, 공원, 공사장(타워크레인·컨테이너), 물류창고, 잔디밭. 건물마다 옆 블록에 유틸리티를 하나 두고, 건물에 가까운 블록부터 사무동·주차 건물·사무동·기숙사·운동장·사무동·연못·기숙사·물류창고·공원 순으로 먼저 채운 뒤, 나머지는 건물과의 거리 띠(가까움·중간·멂)마다 정한 가중치로 정한다. 가까운 띠에는 사무동·주차·유틸리티가, 먼 띠에는 공사장·잔디·공원·연못이 많다.
3. **모든 것은 사업장 이름에서 정해진다.** 난수는 그 이름의 씨앗으로만 굴려 열 때마다 같다. 각 블록의 배치는 블록 안 좌표로 적고 4분의 1 회전으로 도로 쪽을 향하게 돌린다.
4. **그림은 합쳐 그린다.** 가로수·주차된 차는 인스턴스로, 나머지 정적 물건은 재질별 하나의 메쉬로 합쳐(Baker) 그리기 호출을 묶는다. 파사드는 창문 격자 무늬 질감을 쓴다.
5. **지도에서 옮긴 건물과 주차장은 건드리지 않는다.** 블록 배치가 먼저 비켜 서고, 나무는 건물·도로·주차 구역을 피한다.

## 이유
- 격자와 가중치만으로 사업장마다 다른 모습이 나오고, 같은 곳은 늘 같아 사람이 기억하는 장소가 된다.
- 사진을 보지 못한 채 사진을 베끼면 엉터리가 된다. 일반적인 캠퍼스 시설을 흉내 내고 그렇게 말하는 편이 정직하다.

## 버린 대안
- **사업장마다 손으로 배치**: 사업장이 늘 때마다 사람이 해야 한다.
- **무작위 흩뿌리기**: 도로·주차와 건물이 어울리지 않아 현실감이 떨어진다.

## 결과
- 한계: 사진을 보고 만든 것이 아니다. 실제 건물 위치는 지도에서 읽은 파란 지붕만 근거이고, 나머지 시설은 일반적 모양이다.
- 한계: 팹과 유틸리티 사이의 파이프 랙 다리는 아직 없다.
- 한계: 같은 블록이 사업장을 바꿔도 비슷해 보일 수 있다(가중치와 씨앗이 달라 완전히 같지는 않다).
