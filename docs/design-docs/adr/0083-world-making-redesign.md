# ADR-0083 세계 만들기는 결과를 고르고, 빌더는 고른 것 하나에 할 일 하나다

## 맥락
클로즈 베타 첫 사용자가 "세계 만들 때 설정이 너무 많고 어디에 뭐가 있는지 모르겠어서 포기했다"고 했다(베타 피드백 4·12). 연수 님의 기준은 분명하다. **설명 없이도 직관적으로 쓸 수 있어야 하고, 용어와 표현도 UX다.** 검토는 `docs/design-docs/world-builder-review.md`에 있다(어긋난 원칙 1~20, 두 번째 검토의 글 고치기, 다시 그린 화면). 승인된 목업은 새 세계 카드 셋 → 사업장+규모 → 작게 시작 → 빌더 전체 화면이다.

## 결정
1. **새 세계는 "방법"이 아니라 "결과"를 고른다.** 첫 화면은 카드 셋: "사업장 그대로"(추천, 기본 포커스), "작게 시작", (가져오기는 ADR-0084로 없앤다). 카드마다 그림과 한 줄 결과.
2. **사업장 그대로 = 사업장 카드 + 규모 하나 + 결과 문장.** 규모는 작게·보통·실제 그대로 셋이고 각각 랙 수와 걸리는 시간을 보여 준다. 고를 때마다 "랙 10,502대 · 서버 17,300대 · 전력 90 MW — 실제 화성사업장 규모예요"가 뜬다. 열네 칸은 "더 정하기"에 접고 건물·서버룸·서버 세 묶음으로, 칸마다 쉬운 말 한 줄. "상세 모델링 비율"은 화면에서 없애고 자동. 시드는 "같은 세계 다시 만들기 번호"로 고급에.
3. **작게 시작은 이름 하나.** 빈 땅이 아니라 땅 하나·건물 하나·서버룸 하나(컨테인먼트 둘, 랙 24대)인 작은 사업장을 연다.
4. **다음 할 일 칩.** 세계 상태의 순수 함수(땅 없음 → 건물 없음 → 서버룸 없음 → 비어 있음 → 돌려 보기 안 함 → 다 됨)가 칩 하나를 정하고, 누르면 그 자리로 간다. 둘러보기는 이 칩의 연장이다: 첫 "작게 시작"에서 한 번만 "둘러보기 할까요?"를 묻고, 예면 칩이 5단계를 차례로 가리킨다.
5. **빌더의 오른쪽은 고른 것 하나, 할 일 하나.** 이름 · 상태 한 줄 · 상태가 정하는 주된 버튼 하나(비었으면 채우기, 꽉 찼으면 넓히기, 다 됐으면 돌려 보기) · "고칠 곳 n ▸" 한 줄 · 접힌 절 셋(크기와 모양 / 냉방과 전기 / 돈). 
6. **실험에 들어가는 숫자가 앞, 나머지는 접힌다.** 3D 위 한 줄은 랙 · 서버 · 발열/냉방 · 전원 여유다. **돈은 그 줄에서 빠지고** 접힌 "돈" 절과 놓는 순간의 툴팁에만 있다. 테라리움에서 돈은 양념이지 목적이 아니다. 이 원칙은 뒤에 오는 모든 화면에 적용한다.
7. **왼쪽은 "여기서 할 일".** 그 자리에서 놓을 수 있는 것만, 묶음마다 큰 버튼 하나와 쓰임새 이름의 목록("냉방기 — 인로우 30 kW"). 값은 목록에서 뺀다. 놓을 자리가 없으면 목록 대신 한 줄과 버튼. 키 설명은 "조작법 ?" 뒤로, "끌면 화면이 움직여요"는 첫 끌기 뒤 사라진다.
8. **한 문장은 한 곳에.** 막힌 이유는 손잡이·커서 옆 토스트 한 번, 패널에는 상태 줄만. 같은 숫자를 두 군데 보이지 않는다.
9. **주된 버튼은 하나, 저장은 자동.** 위 막대는 "돌려 보기" 하나와 "저장됨 · 방금" 상태 글자. 조각 덧붙이기의 네 방향 버튼은 없애고 3D의 + 손잡이만 둔다.
10. **말을 고친다.** 데이터 홀 → 서버룸(생성기 이름까지), 먹이는 설비 → 전기, 타일 수 삭제(m²만), 꺼진 버튼은 이유를 버튼에, 선택지는 결과로("서버 절반쯤 → 랙마다 서버 7대, 전력 4 kW"), 버튼은 결과를 말한다("화성사업장 만들기"). 숫자는 아라비아 숫자 + 단위, "~할 수 있어요" 겹치기 금지. 용어집에 "숫자와 단위" 절을 더한다.
11. **UX 여정 `build-small`**(작게 시작 → 채우기 → 돌려 보기, 손 수 예산 8)을 더해 이 결정을 잰다.

## 고려한 대안
- **가이드(둘러보기)만 더하기**: 가이드가 필요하다는 것 자체가 설계의 실패다. 가이드는 칩의 연장으로만 둔다.
- **열네 칸을 설명문으로 보강하기**: 칸 수가 문제지 설명이 부족한 게 아니다.

## 결과
- REQ-077이 이 결정을 요구사항으로 적는다. 홈·빌더·새 세계 화면의 글을 비교하는 잠긴 시험은 별도 ADR의 `amends_tests`로 고친다.
- 돈 중심의 상단 숫자줄(`들인 돈`)과 패널의 큰 숫자 셋이 사라진다.
