# ADR-0134 베타 피드백 3차: 내 카드만으로, 숫자는 하나로, 오른쪽 아래는 비워서

제품 책임자가 ADR-0132를 받아 써 보고 네 가지를 더 알려 줬다 (REQ-111). 결정은 다섯이다.

1. **IAP는 다른 서비스와 똑같이 뺄 수 있다.** 서비스 줄의 "빼기"는 마지막 하나에도 있다. 내 카드 하나만 남기면 ②는 "<내 카드 이름>은 어떻게 돌리나요?"와 "서비스 1 / 1"을 묻고, ③의 서버 수는 고른 서비스의 숫자로만 세며, 세계도 실험도 IAP 없이 만들어진다. 서비스가 0개면 "다음"은 막히고 이유 한 줄("서비스를 하나는 골라야 다음으로 갈 수 있어요")이 ① 아래에 보인다. 초안은 서비스 목록을 그대로 두므로 뺀 것도 "이어서"에서 기억한다. ①의 안내는 "처음에는 IAP가 들어 있고, 빼도 돼요"로 IAP가 있든 없든 참이다. 이름을 건드리지 않은 세계는 IAP가 없으면 첫 서비스를 따른다("내 정산 웹 실험용").
2. **③은 숫자를 한 번만 센다.** 왼쪽 합계("서버 120대 · 랙 7대 (서버 랙 6 + 기반 랙 1) · 서버룸 1곳"), 아래 한 줄(스위치·PDU·냉방기·kW), 시작 줄은 모두 `sizeView`(= `planShape`와 `worldTotals`)가 만든 글이다. 오른쪽의 호스트·VM·스위치·가격 타일은 왼쪽과 다른 계산이라 없앴다. 오른쪽은 "이 크기에서 일어나는 일"이라는 말뿐인 열이고(멈추는 고장 / 느려지는 고장 / 살리는 길, 각 셋까지와 "외 n가지", 시나리오 수 한 줄), "세계를 다 지었어요"의 한 줄 사실도 지은 세계가 센 서버·랙·서버룸으로 말한다.
3. **지은 세계의 크기는 계획과 같다.** 전에는 120대·랙 6대를 계획하고 131대·랙 7대를 지었다. 차이는 둘이었다: 줄마다 맨 앞의 기반 랙(스파인 스위치와 스토리지, 서버 없음)과, 랙마다 1U·2U 서버를 섞어 채워 생긴 서버 수의 흔들림. 이제 세 숫자가 있는 스펙은 생성기에 `serversPerRack`(랙마다 정확히 그만큼, 모자라면 1U 서버로 맞춘다)과 `computeRacks`(서버 랙 수를 서버룸에 고르게 나누어 그 수만 짓는다)를 준다. 기반 랙은 `props.infra`가 붙어 세계에서 알아볼 수 있고, 화면은 "랙 7대 (서버 랙 6 + 기반 랙 1)"처럼 나누어 말한다(③, 빌더 아래 막대, 서버룸·건물 카드). 고밀도(GPU·액체 냉각) 랙은 서버 랙에 든다. 옛 `servers`만 있는 스펙은 예전과 같은 세계다.
4. **빌더 오른쪽 아래는 한 줄 칩 하나다.** "지금 일하는 에이전트 5"가 같은 줄 다섯으로 펼쳐져 이끼 알약과 "다음:" 버튼을 덮었다. 이제 "에이전트 5개가 일하는 중" 한 줄 칩이고 누르면 칩 위로 목록이 열린다(같은 에이전트는 "운영 (규칙 기반) ×5"). 아래에서 위로 막대 → "다음:" 칩 → 에이전트 칩 → 이끼 알약 순이고, 높이는 `--bottom-bar-h`(막대가 두 줄이 되는 폰에서도)를 따른다.
5. **UX 측정이 이것을 지킨다.** 여정 `own-card-only`(예산 18)가 내 카드를 저장하고 IAP를 빼고 0개 상태를 보고 끝까지 가서 세계를 연 뒤, 1440·1280·1024·390px에서 칩 셋과 아래 막대의 상자가 겹치지 않는지 잰다(`tests/e2e/ux/overlap.ts`). `docs/generated/ux-score.json`은 `build-small`·`topology`가 빠져 UX004였으므로 열두 여정 모두를 다시 쟀다.

## 시험과 잠금
새 시험은 `[REQ-111]`을 달았다. 잠긴 시험은 고치지 않았다. `shaped-sizing.test.ts`의 `sizeTotals`는 그대로 두고 새 `worldTotals`를 더했다. 보호 경로는 `harness/src/ux/score.ts`(여정 하나의 예산과 이름)와 요구사항, 다시 잠근 `test-lock.json`이다.

## 측정 방법
이 환경은 소프트웨어 GL이라 느려서 `pnpm ux`의 8분 한도로는 모자란다. `runChild`에 40분 한도를 준 채 `main`을 부르는 한 줄(`tsx -e`)로 같은 측정을 돌렸고 `TERRARIUM_UX_GRAPHICS=min`을 썼다. 하한(`ux-floor.json`)은 낮추지 않았다.

## 하지 않은 것
- "처음부터 하기"는 IAP로 되돌린다(예전과 같다).
- 고밀도 랙이 있는 방의 서버 랙 수는 계획이 세는 대로 짓고 방마다 고르게 나누지는 않는다(합계는 시험이 같음을 확인한다).
