# ADR-0152 현실에서 만든 세계는 관리자가 다루고 복사해서 실험하며, 엑셀과 SPL이 첫 길이다

## 맥락
설계 담당이 제품 책임자에게 요구사항에서 정할 것 넷을 물었고 답을 받았다(2026-11-11).

1. 현실 데이터로 지은 세계에 직접 실험하지는 않지만, 복사해서 실험 환경을 만들 수 있어야 한다.
2. 데이터를 넣고 온톨로지를 관리하는 일은 일단 관리자 기능으로만 둔다. 나중에 로그인·권한이 생기면 관리자가 권한을 준 사람만 한다.
3. 클로즈 베타에 들어간다.
4. 위치·전원·냉방은 엑셀로 받을 수 있어야 한다. 위치나 전원 일부는 다른 소스에 있을 수도 있다. Splunk에서 SPL로 가져오는 길이 중요하다.

대조한 것:
- 신원은 지금 둘 중 하나다: SSO 프록시가 넣는 헤더, 또는 사람이 직접 적는 이름(`http/identity.ts`, ADR-0028·0044). 관리자라는 개념은 없다. 직접 적는 이름은 누구나 적을 수 있다.
- ADR-0149 3번은 "쿼리 말을 받는 소스는 정해 둔 검색만 돌린다"였다. 4번 답과 부딪힌다.
- ADR-0150은 "그 세계에서의 실험 준비"를 범위 밖에, "같은 것 알아보기"를 둘째 걸음에 뒀다. 1번·4번 답과 부딪힌다.

## 결정
1. **현실에서 만든 세계에서는 직접 실험하지 않고, 복사해서 실험 세계를 만든다.** 복사본은 보통의 실험 세계다. 손으로 고칠 수 있고 원본이 바뀌어도 바뀌지 않으며 어느 판에서 떴는지 기억한다. 원본의 "모름"은 복사할 때 흔한 방식으로 채우거나(보고서를 남긴다) 사람이 채운다. 실험 전의 검사는 다른 세계와 같다. ADR-0150의 "실험 준비는 범위 밖"을 이것이 대신한다.
2. **소스·주기·손질·대응·관계 규칙·모델의 관리는 관리자만 한다.** 지금은 서버 설정의 관리자 목록이다. 신원이 프록시에서 올 때만 이름을 믿고, 이름을 직접 적는 방식에서는 서버에 둔 관리자 토큰이 있어야 한다. 권한이 생기면 관리자가 준 사람이 한다.
3. **현실에서 만든 세계는 관리자가 공개하기 전까지 관리자만 본다.** 공개하면 다른 사람이 보고 복사한다. 비밀 값과 받은 그대로는 늘 관리자만 본다. (제품 책임자가 말한 것은 2번까지다. 3번은 "현실의 구성이 로그인 없는 곳에서 누구에게나 보이지 않게"를 위한 설계 담당의 기본값이다.)
4. **REQ-115는 클로즈 베타에 들어간다.**
5. **엑셀이 위치·전원·냉방의 주된 길이다.** 양식(랙 위치, 전원 계통, 냉방 계통)을 주고, 양식대로면 대응 없이 받는다. 자유로운 엑셀도 대응으로 받는다.
6. **같은 것 알아보기 규칙과 속성마다 이기는 소스는 첫 걸음에 넣는다.** 같은 장비의 위치·전원은 엑셀에, 구성은 다른 소스에 있기 때문이다. ADR-0150의 "둘째 걸음"을 이것이 대신한다.
7. **Splunk는 SPL로 가져오고, 구성 소스로도 쓴다.** 검색 하나가 표 하나다. SPL은 관리자가 적는다. 지킴은 세 겹이다: Splunk 쪽 읽기 전용 역할의 계정(본선), 테라리움의 명령 허용 목록(Splunk가 위험하다고 정한 명령과 모르는 명령을 거절), Splunk의 위험 명령 검사를 끄지 않음. 검색마다 시간 범위와 줄 수 한도를 둔다. ADR-0149 3번을 이것이 대신한다.
8. **첫 걸음의 순서**: 엑셀(양식) → Splunk(SPL) → vROps 프리셋(왕복 시험).

## 확인한 것과 못 한 것
- Splunk가 위험하다고 정한 명령의 목록은 Splunk 문서에서 확인했다.
- 일반 검색 작업을 REST로 돌릴 때 그 검사가 걸리는지는 확인하지 못했다(후처리 검색에서는 걸린다). 그래서 테라리움의 허용 목록과 계정 권한을 겹쳐 둔다.
- 매크로와 저장된 검색이 풀린 뒤의 명령은 테라리움이 볼 수 없다. 그래서 계정 권한이 본선이다.

## 버린 길
- **현실에서 만든 세계에서 바로 실험**: 실험은 세계를 바꾼다(고장, 조치). 데이터가 정하는 세계가 실험으로 바뀌면 다음 동기화와 싸운다.
- **이름으로만 관리자 정하기**: 로그인 없는 지금은 누구나 그 이름을 적을 수 있다.
- **SPL을 정해 둔 검색으로만**: 무엇을 꺼낼지는 데이터를 가진 쪽이 안다.
- **막는 목록으로 SPL 거르기**: 새 명령이 생기면 뚫린다.
