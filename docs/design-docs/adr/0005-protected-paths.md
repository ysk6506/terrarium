# ADR-0005 보호 경로

## 맥락
검사를 만들어도 검사 자체를 고치면 통과시킬 수 있다. 가드레일은 가드레일을 못 고치게 해야 한다.

## 결정
`harness/**`, `pyproject.toml`, `Makefile`, `.github/**`, ADR, 요구사항, `AGENTS.md`는 보호 경로다.
- 이 경로를 바꾸는 변경에는 같은 변경에서 **새로 추가된**, 봉인된 ADR이 `touches_protected`로 그 경로를 명시해야 한다 (`PROT001`, `PROT002`).
- 과거 ADR은 새 변경을 허가할 수 없다. 허가는 변경과 같은 시점의 결정이어야 한다.
- `CODEOWNERS`가 모든 보호 경로를 지정해야 한다 (`PROT003`). 저장소 호스트의 브랜치 보호에서 코드 소유자 승인을 필수로 켜야 마지막 고리가 닫힌다.
- 잠금 파일, 부채 기준선, 커버리지 하한은 한 방향으로만 바뀌는 래칫이라 ADR 대신 각자의 `--base` 검사로 지킨다.

## 이유
사람이 개입하지 않는 개발에서 가드레일을 바꾸는 일은 가장 위험한 행동이다. 흔적과 이유를 반드시 남기게 한다.

## 한계
호스트의 브랜치 보호는 저장소 밖 설정이라 이 저장소만으로는 강제할 수 없다. 설정 방법은 하네스 가이드에 적었다.
