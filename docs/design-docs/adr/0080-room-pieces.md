# ADR-0080 방은 직사각형 조각을 붙인 하나의 공간이다

## 맥락
ADR-0079에서 "모양은 직사각형, L자는 방 둘로"라고 했다. 연수 님이 바로 짚었다. 실제 서버룸은 크기가 다른 직사각형 둘이 붙은 육각형 윤곽인 경우가 있다. 그것은 방 둘이 아니라 **하나의 방**이다. 벽이 없고, 공기가 섞이고, 사람이 가로질러 다니고, 알람과 온도가 한 방의 것이다. 방 둘로 쪼개면 시뮬레이션이 거짓이 된다(방마다 온도가 따로 돈다).

## 결정
1. **방의 자리는 조각 목록이다.** `placement: { type: "area", x, y, w, d, pieces?: Rect[] }`. 첫 직사각형이 본체이고 `pieces`는 덧붙인 조각이다. 조각은 본체나 다른 조각과 변을 맞대야 하고(겹치거나 떨어지면 거부), 전부 건물 바닥 안이어야 한다. 조각이 없으면 지금과 똑같은 직사각형이라 기존 세계·체크포인트·digest가 그대로다.
2. **방은 하나다.** 엔티티 하나, 알람 하나, 온도 하나(`ambientC`), 사람 경로 하나. 랙·컨테인먼트·설비는 조각들의 합집합 안에 놓이면 된다. 타일은 조각마다 깔리고 조각 경계에는 벽도 선도 없다.
3. **벽은 합집합의 윤곽이다.** 조각들을 합친 직교 다각형 윤곽(rectilinear outline)을 따라 벽·문·몰딩을 그린다. 2D 지도와 3D가 같은 윤곽을 쓴다. 바닥 온도장은 윤곽 안에서만 칠한다.
4. **화면.** 방을 고르면 변마다 "조각 덧붙이기" 손잡이가 있다. 끌어내면 그 변에 새 조각이 붙고, 조각을 고르면 크기를 바꾸거나 떼어 낸다(안의 장비가 잘리면 막는다). 건설비는 조각 면적의 합으로 센다.
5. **생성기**는 당분간 직사각형 방만 만든다. 조각은 사람이 붙인다.

## 버린 대안
- **다각형 자유 그리기**: 비스듬한 벽은 타일·컨테인먼트·공기 흐름 계산을 다 바꾼다. 직교 조각이면 전부 직사각형 수학 그대로다.
- **방 둘 + "연결됨" 표시**: 온도·알람·사람이 두 방으로 갈린다. 거짓이다.

## 한계
- 조각은 변을 맞대야 한다. 꼭짓점만 닿는 배치는 허용하지 않는다.
- 조각 경계에 걸친 컨테인먼트는 허용하되, 온도장은 조각 단위 격자를 합쳐 칠하므로 경계에서 아주 미세한 단절이 보일 수 있다.
