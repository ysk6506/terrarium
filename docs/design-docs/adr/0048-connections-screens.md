# ADR-0048 연결 화면

## 맥락
ADR-0042·0043으로 서버는 하네스와 에이전트를 연결·보관·버전 관리하게 됐다. 사용자는 이것을 "화면에서 쓰는 것"으로 원한다. 토큰을 직접 적고, 헤더를 붙이고,
메타데이터를 달고, 안 쓰면 지워진다는 안내를 보고, 에이전트가 바뀐 것을 버전으로 본다. 화면이 없으면 서버의 기능은 설정 파일을 고치는 사람만 쓸 수 있다.

## 결정
1. **메뉴에 "연결"을 둔다**(자물쇠가 아니라 플러그 아이콘). 화면은 둘이다: `/connections`(목록)와 `/connections/:id/agents/:agentId/versions`(에이전트 버전).
2. **연결 만들기·고치기는 한 창(Dialog)에서 한다.** 입력 칸은 커넥터가 스스로 설명한 것(`ConnectorSpec.fields`)을 그대로 그린다. 화면은 프로토콜을 모른다.
   - 맨 위에 `toolGuide`(도구가 어떤 길로 가는지)를 보여 준다. 칸 종류 `secret`은 가려진 입력, `env`는 서버 환경 변수 이름이다.
   - 이미 저장된 비밀 칸은 "설정됨"이라 보이고, 비워 두면 그대로, 새로 적으면 교체, "지우기"를 누르면 `null`을 보낸다.
   - 드물게 쓰는 칸(`advanced`), 커스텀 헤더, 메타데이터는 접어 둔다.
   - 저장 전에 "연결 확인"을 누르면 저장 없이 연결해 보고, 되면 발견한 에이전트와 걸린 시간을, 안 되면 무엇을 바꿀지를 보여 준다.
3. **목록은 연결마다 한 줄에 상태·주인·출처("서버 설정"인지)·남은 기간을 보여 준다.** 화면에서 만든 연결은 7일 안에 지워지면 "안 쓰면 N일 뒤 지워진다"를 눈에 띄게 하고 "계속 쓰기"를 곁에 둔다. 설정 파일의 연결은 고치기·지우기가 없다.
4. **모든 화면 위에 지워질 연결의 안내 띠를 둔다**(`meta.expiring`). "계속 쓰기"가 있는 연결 화면으로 가는 링크가 함께 있다.
5. **에이전트 버전은 한 화면에서 본다**: 새 버전부터, 어느 필드가 이전→이후로 어떻게 바뀌었는지, 날짜, 만든 사람, 이 버전으로 돌린 실험 수. 사람이 이름표·메모·속성을 더하고 고치고 지운다.
   "지금 실험을 만들면" 칸은 새 버전이 생길지, 생기면 무엇이 달라지는지를 미리 보여 준다. 에이전트를 지금 볼 수 없으면(연결이 끊김) 이유를 말한다.
6. **실험 만들기 마법사**는 연결이 하나도 없으면 "연결 화면에서 하네스를 먼저 연결한다"로 안내하고, 에이전트를 고르면 새 버전이 생길지 미리 보여 주며, 실험에 메타데이터를 달 수 있다. 실험 목록은 메타데이터로 거를 수 있다.
7. **화면 로직은 순수 함수로 두고**(`logic/connections.ts`) 화면은 그리기만 한다: 폼의 시작값, 보낼 값, 빠진 것, 남은 기간 문장, 안내 띠 문장.

## 이유
- 사용자가 연결하는 대상(OpenClaw, GoClaw, Hermes, OpenCode, LangChain, LangGraph…)은 계속 늘어난다. 화면이 프로토콜을 모르면 커넥터만 더해도 화면이 따라온다.
- 비밀은 되돌려 받지 못하므로 화면이 "비워 두면 그대로"를 분명히 말해야 사람이 실수로 지우지 않는다.
- 지우기 전에 안내는 모든 화면에 보여야 한다. 연결 화면에 오지 않는 사람에게도 닿는다.

## 버린 대안
- 설정 화면에 하네스를 숨기기: 연결은 실험을 만드는 첫 단계이므로 메뉴에서 바로 보여야 한다.
- 커넥터마다 전용 화면: 커넥터가 늘 때마다 화면을 고쳐야 한다.

## 결과
- 한계: 화면은 글자 크기·접근성만 확인했고 실제 하네스에 붙여 본 적은 없다(서버는 가짜 하네스로만 확인).
- 한계: 비밀 값을 잃어버리면 다시 입력해야 한다(서버 열쇠가 바뀐 경우 포함).
