# ADR-0159 관문의 브라우저 설치는 시스템 꾸러미 없이 하고, 다시 해 본다

## 맥락
`ux-journeys`는 관문(`gate`)에 걸려 있고(ADR-0141), 실행마다 브라우저와 시스템 꾸러미를 내려받아 깐다(`playwright install --with-deps chromium`). 2026-11-11에 문서만 바꾼 PR 둘(#20, #21)이 같은 시각에 같은 이유로 떨어졌다: 러너에서 꾸러미 저장소의 이름을 찾지 못했다("Temporary failure resolving 'security.ubuntu.com'", 설치가 100으로 끝남). 코드와 상관없는 실패가 머지를 막았다. main은 관문이 초록이어야 머지된다.

같은 날 다시 돌려도 한 시간 넘게 같은 실패가 이어졌다(러너의 지역이 달라도 같았다). 짧게 다시 해 보는 것으로는 넘지 못한다. 로그를 보니 `--with-deps`가 이 러너 이미지(ubuntu-26.04)에서 까는 것은 대체 글꼴 꾸러미 아홉 개뿐이었고, 브라우저가 쓰는 라이브러리는 이미지에 들어 있었다. 웹 앱은 제 글꼴(Pretendard)을 함께 싣는다.

## 결정
1. **브라우저만 내려받는다**(`playwright install chromium`, Playwright의 내려받기 주소에서). 시스템 꾸러미(apt)는 깔지 않는다.
2. **브라우저가 뜨는지 바로 확인한다.** 뜨지 않으면 그때만 시스템 꾸러미를 깐다(`playwright install-deps chromium`).
3. 내려받기와 꾸러미 설치는 각각 세 번까지 다시 해 본다(20초, 40초를 쉬고). `ux-journeys`와 `ux-measure` 둘 다.
4. 다시 해 보는 것은 설치뿐이다. 여정과 시험은 다시 돌리지 않는다. 떨어진 시험을 다시 돌려 초록을 만드는 것은 결함을 가린다.
5. 대체 글꼴이 없어져서 여정의 겹침 검사 결과가 달라지면(앱의 글꼴에 없는 글자가 있다는 뜻이다) 이 결정을 되돌리지 않고 그 글자를 앱의 글꼴이나 그림으로 고친다. 사용자의 기계에도 그 대체 글꼴은 없을 수 있다.

## 버린 길
- **다시 해 보기만 하기**(처음 안): 한 시간 넘는 장애를 넘지 못했다.
- **꾸러미를 캐시에 넣기**: 시스템 꾸러미는 러너 이미지에 따라 달라져 캐시가 낡는다.
- **`ux-journeys`를 관문에서 빼기**: 화면의 결함을 막는 관문이다(ADR-0141).

## 결과
`.github/workflows/ci.yml`의 두 걸음.
