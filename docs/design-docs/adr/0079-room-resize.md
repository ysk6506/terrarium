# ADR-0079 서버룸과 건물은 직사각형 안에서 자유롭게 넓히고, 꽉 차면 길을 보여 준다

## 맥락
제품 책임자가 물었다. 서버룸을 실제처럼 구성하려는 사용자가 분명히 생길 텐데 공간이 좁으면 어떡하나. 원하는 크기와 모양으로 넓힐 수 있어야 하나.
지금 빌더의 logic에는 `resizeArea`가 있어 방과 건물의 직사각형을 바꿀 수 있고, 안의 장비가 잘리면 막는다. 그런데 화면에는 손잡이도 입력칸도 없어서 사람이 쓸 수 없다. 생성된 세계의 방은 생성기가 정한 크기 그대로다.

## 결정
1. **크기는 자유, 모양은 직사각형.** 방과 건물은 타일(0.6 m, 건물은 사업장 격자) 단위로 어느 변이든 넓히거나 줄인다. L자 같은 모양은 방 둘로 나눠 만든다(문은 이미 벽에 그려진다). 이유: 직사각형이면 타일·복도·컨테인먼트·공기 흐름 계산이 전부 그대로다.
2. **화면에서 두 가지 방법.** 방이나 건물을 고르면 네 변에 손잡이가 생겨 끌 수 있고, 옆 패널에 가로·세로 입력칸이 있다. 끌면서 타일 수와 늘어나는 건설비(실가격, REQ-059)를 같이 보여 준다.
3. **막힐 때 이유를 말한다.** 안의 랙·설비가 잘리면 "랙 A-03이 밖으로 나가게 돼요. 먼저 옮겨 주세요". 건물 바닥을 넘으면 "건물이 꽉 찼어요. 건물을 넓혀요" 버튼을 바로 준다. 건물이 땅을 넘으면 "내 땅 밖이에요. 옆 땅을 사요"로 이어진다 (REQ-059의 땅 사기).
4. **생성된 세계도 같다.** 생성기가 만든 방은 그냥 방이다. 꽉 차서 랙을 놓을 수 없을 때 빈 자리 안내 대신 "서버룸 넓히기"를 보여 준다.
5. **되돌리기.** 크기 변경은 편집 기록에 들어간다.

## 버린 대안
- **방 모양을 다각형으로**: 타일 깔기, 컨테인먼트, 온도장, 사람 경로가 전부 다각형을 알아야 한다. 직사각형 둘로 같은 모양이 된다.
- **자동으로 넓히기(랙을 놓으면 방이 커짐)**: 사람이 모르는 새 건설비가 늘어난다. 사람이 결정한다.

## 한계
- 줄일 때는 안의 장비를 먼저 옮겨야 한다. 자동으로 밀어 넣지 않는다.
- 층을 더하는 것은 이 ADR 밖이다(층은 건물 만들기에서 정한다).
