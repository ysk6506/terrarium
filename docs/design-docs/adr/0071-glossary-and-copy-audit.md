# ADR-0071 화면의 말은 용어집 하나로 정하고, 글 전체를 한 번 점검한다

## 맥락
ADR-0070에서 블록 이름을 "고장 일으키기", "고장 고쳐지기"로 정했다. 연수 님이 말했다. "고쳐지기"는 한국 사람이 쓰는 말이 아니고 어색하다. 이런 것이 테라리움에 많을 것이다.
맞다. 화면 글을 한 번에 한 줄씩 쓰다 보니 번역투와 만든 말이 섞였고, 같은 것을 다른 말로 부르는 곳도 있다(툴 호출 한도 / 상한). 말을 고치는 기준이 한 곳에 없어서 고칠 때마다 다시 흔들린다.

## 결정
1. **[용어집](../glossary.md)이 화면 말의 기준이다.** ADR-0070의 3번 중 블록 이름은 용어집을 따른다: "고장 발생", "고장 복구", "고장 종류", "세부 설정". 명사형이고, 팔레트의 다른 블록(대기, 분기, 메모)과 결이 같다.
2. **글 전체를 한 번 점검한다.** `apps/web`, `packages/core`, `apps/server`에서 사람에게 보이는 한국어 문자열을 전부 뽑아 번역투, 만든 말, 같은 것의 다른 이름, 영문 코드 누출을 표로 만들고, 고친 뒤 용어집에 결정을 더한다. 점검 결과는 용어집 옆에 "글 점검" 문서로 남긴다.
3. **판단 기준은 하나다.** 동료에게 말로 설명할 때 쓸 말인가. 아니면 바꾼다.
4. 시험은 용어집의 "쓰지 않는 말"이 화면 글에 없는지만 본다. 자연스러운지는 사람이 본다.

## 버린 대안
- **ADR-0070을 폐기하고 새로 쓰기**: 그 ADR의 나머지 11가지는 그대로 맞다. 이름만 용어집으로 옮긴다.
- **말을 그때그때 고치기**: 지금까지 그렇게 해서 이렇게 됐다.

## 한계
- 용어집은 자라는 문서다. 처음에는 편집기의 말만 담겼다.
